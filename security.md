# Security Policy

## Supported Versions

Security fixes are applied to the latest release. Older releases are not supported.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Please **do not** create a public issue for security vulnerabilities.
Instead, email [fern-security@ftbxx1.dev](mailto:fern-security@ftbxx1.dev)
or open a private vulnerability report via
[GitHub's security advisory feature](https://github.com/ftbxx1/Fern/security/advisories/new).

You should receive a response within a few days. Please include:

- The Fern version and Minecraft / Fabric versions affected
- A description of the vulnerability and its impact
- Steps to reproduce, if possible

We ask that you keep vulnerabilities private until a fix is released.
